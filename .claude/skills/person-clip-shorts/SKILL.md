# 인물 명장면 쇼츠 스킬 (장면 발굴 → 구간 추출 → 60초 대본 → 편집 지시서)

사용자가 인물 이름을 직접 주고 쇼츠를 요청할 때 쓰는 루틴이다. 결과물은 **60초 쇼츠(9:16) 한 편**만 만든다. 5분 클립 같은 긴 형식은 만들지 않는다.

## 0. 입력 확인

요청에서 아래 값을 읽는다. 없으면 기본값을 쓰고, 묻지 않는다.

| 항목 | 기본값 |
|---|---|
| 인물 | (필수. 없으면 그때만 묻는다) |
| 시기·분야 구분 3가지 | 인물 경력에 맞춰 직접 정한다 (예: 씨름 선수 시절 / 예능 초창기 / 레전드 예능) |
| 장면 후보 수 | 10개 |
| 쇼츠로 만들 장면 | STEP 1의 1위 장면 (사용자가 번호를 지정하면 그 장면) |
| 원본 소스 파일 | 없음 (없으면 STEP 2에서 유튜브 영상으로 구간 녹화) |

"오늘" 날짜가 필요하면(폴더명 등) `date -u`에 9시간을 더한 **서울 기준 날짜**를 쓴다.

## STEP 1. 장면 발굴

- 웹 검색으로 찾는다. 시기·분야 3가지를 골고루 섞어서 **화제성 높은 순 10개**.
- 장면마다: 프로그램명, 방영 연도·회차, 장면 요약, 재밌는 포인트, 원본 영상 검색 키워드.
- 유튜브에 **방송사 공식 클립**이 있으면 링크와 타임스탬프. 직접 확인 못 했으면 "확인 필요".
- 확인 안 된 정보(회차 번호, 대회명, 정확한 발언 등)는 모두 **"확인 필요"**로 적고 지어내지 않는다. 자료마다 다르면 "자료마다 다름"으로 둘 다 적는다.
- 장면마다 **원음 필요 여부**를 판단한다. 대사·포효·리액션·연주처럼 소리가 핵심이면 "원음 필요", 아니면 "무음 가능".

출력:

| 순위 | 구분 | 프로그램 | 방영일·회차 | 장면 요약 | 재밌는 포인트 | 검색 키워드 | 공식 클립·타임스탬프 | 원음 필요 여부 |

표 아래에 출처 링크를 정리한다.

## STEP 2. 구간 추출

- 대상: 쇼츠로 만들 장면 1개. 같은 장면을 다룬 후속 방송(회고, 리턴매치 등)이 있으면 60초 안에서 짧게 섞어도 된다.
- 결과 영상은 사용자가 **비공개로 업로드**해서 쓰는 용도다. 구간 녹화(추출)는 확인 없이 진행한다.
- 소스 우선순위: ① 사용자가 준 원본 파일 → ② STEP 1에서 찾은 방송사 공식 유튜브 클립 → ③ 그 밖의 유튜브 영상(검색 키워드로 찾은 것).
- 60초 안에 들어가게 구성하고, 한 구간은 **5~10초 이내**.
- 소리가 핵심인 구간 → **원음 포함**으로 추출. 나머지 → **영상만**(오디오 없이) 추출.
- 욕설이 들어간 원음도 **별도 처리 없이 그대로** 추출한다.

출력:

| 클립ID | 소스(영상명·링크) | 원본 구간 | 내용 | 오디오(원음 포함 / 영상만) | 욕설 포함 여부 |

- 클립ID는 소스 알파벳 + 순번 (A1, A2, B1 …).
- 링크·타임스탬프를 확인 못 한 구간은 "확인 필요".

### 구간 녹화 (실제 클립 파일 만들기)

추출표를 만든 뒤 클립ID별 파일을 `clips/`에 만든다. 파일명은 클립ID와 같게 한다.

1. 도구 확인: `ffmpeg`, `yt-dlp`. yt-dlp가 없으면 `pip install yt-dlp`로 설치한다.
2. 유튜브 소스는 필요한 구간만 받는다 (앞뒤 1초 여유):
   ```bash
   yt-dlp -f "bv*[height<=1080]+ba/b" --download-sections "*<시작-1초>-<끝+1초>" \
     --force-keyframes-at-cuts -o "src/<소스ID>_<순번>.%(ext)s" "<유튜브 URL>"
   ```
3. ffmpeg로 정확히 자르고 오디오를 정리한다:
   ```bash
   # 원음 포함
   ffmpeg -ss <시작> -to <끝> -i <원본> -c:v libx264 -crf 18 -c:a aac -b:a 192k clips/A1.mp4
   # 영상만 (오디오 없음)
   ffmpeg -ss <시작> -to <끝> -i <원본> -c:v libx264 -crf 18 -an clips/A2.mp4
   ```
4. 만든 클립마다 `ffprobe`로 길이와 오디오 트랙 유무가 추출표와 맞는지 확인한다.
5. 다음 경우엔 그 구간을 건너뛰고 추출표에 이유를 적는다. 나머지 구간은 계속 진행한다.
   - 유튜브 접속이 막힘 (네트워크 정책, 403 등) → "녹화 실패: 접속 차단"
   - 영상이 삭제·비공개·지역 제한 → "녹화 실패: 영상 없음"
   - 타임스탬프를 확인 못 함 → 영상을 받아 장면을 직접 찾고, 못 찾으면 "녹화 실패: 구간 확인 필요"
   - 네트워크 차단을 우회하려고 프록시 설정을 바꾸거나 다른 경로를 쓰지 않는다.

## STEP 3. 60초 쇼츠 대본

### 제작 방식
- **나레이션 없음.** 모든 정보는 자막으로만 전달한다.
- 영상 전체에 BGM이 깔린다.
- STEP 2에서 "원음 포함"으로 추출한 구간만 원본 음성을 쓴다.

### 자막 말투
- 커뮤니티 말투: "~함", "~임", "ㄷㄷ", "ㅋㅋ", "레전드".
- **쓰지 않는다:**
  - "실화냐"
  - "~한 썰임" 같은 문장
  - "여기서 다들 ~함", "다들 소름 돋았다고 함"처럼 시청자 반응을 짐작하는 문장
  - "오늘은 ~" 처럼 영상 주제를 본문에서 문장으로 설명하는 문장
- 자막 한 줄은 약 15자 이내로 짧게, 한 줄에 한 호흡.
- 첫 3초 자막은 결과나 충격 포인트를 먼저 던지는 훅.
- 첫 3초 훅 구간에는 욕설이 들어간 원음을 쓰지 않는다 (광고 제한 방지).
- 마지막은 **질문 없이 한 줄 감상평**으로 끝낸다. 댓글 유도 질문은 쓰지 않는다.

### 사실·윤리
- STEP 1에서 확인된 사실만 쓴다. 과장은 `(※드립)`을 붙여 드립인 게 티 나게 한다.
- 기록마다 다른 발언은 자막으로 직접 인용하지 않고 `※ 기록마다 다름`으로 표시한다. 원음으로 들리는 대사는 그대로 쓴다.
- 실존 인물 비하, 근거 없는 루머는 넣지 않는다. 언론이 붙인 사건명(예: '깝죽 사건')은 이름으로만 쓰고 인물 평가로 쓰지 않는다.

### 출력

| 시간 | 화면(클립ID) | 자막 | 오디오 |

- 총 길이 60초 이내.
- 화면: STEP 2의 클립ID. 원본이 아닌 화면(연도·프로그램명 자막 카드, 자료사진)은 내용을 적는다.
- 오디오: "BGM" 또는 "원음 + BGM 줄임". 원음이면 들려줄 포인트(대사, 포효 등)를 적고, 욕설이면 "욕설 포함".
- 표 아래에 **업로드 전 확인할 사항**(확인 필요 항목, 원본으로 대조할 장면)을 적는다.

## STEP 4. 편집 지시서

편집자나 편집 도구에 그대로 넘길 수 있게 아래 규칙을 대본과 함께 적는다.

### 입력 자료
- STEP 2 구간 추출표, STEP 3 대본 표
- 클립 파일: 클립ID와 같은 이름 (A1.mp4, A2.mp4 …)
- BGM 파일: 사용자가 지정 (없으면 "BGM 파일 지정 필요")

### 컷 편집
- 대본 표 순서와 클립ID대로 배치, 한 컷 최대 10초, 총 60초 이내.
- 9:16 (1080x1920), 인물이 화면 가운데 오도록 크롭.
- 첫 3초는 훅 장면 확대 + 효과음 1회. 욕설 원음 클립은 첫 3초에 두지 않는다.
- 전환은 하드컷 위주. 장면이 크게 바뀌는 곳(연도 변경 등)에만 짧은 전환.
- 연도·프로그램명은 자막 카드(검정 배경 + 큰 글자, 1~2초).

### 오디오
- BGM은 영상 전체, 기본 -18 ~ -20 LUFS.
- "원음 + BGM 줄임" 구간: 원음을 앞에 두고 BGM은 -30dB 수준, 앞뒤 0.3초 페이드.
- "BGM" 구간: 원본 소리 없이 BGM만.
- "욕설 포함" 구간: 처리 없이 원음 그대로.
- 무음이 포인트인 구간(눈맞춤 등)은 BGM도 잠깐 줄여 정적을 살린다.
- 최종 음량 -14 LUFS.

### 자막
- 대본 표 문구 그대로, 수정하지 않는다.
- 화면 중앙보다 약간 아래, 굵은 고딕, 흰 글씨 + 검은 외곽선.
- 쇼츠 하단 UI(제목·버튼)에 가리지 않게 아래쪽 약 20%는 비운다.
- 한 화면 최대 2줄. 원음 대사 구간은 대사 타이밍에 맞춰 표시하고, 들리는 그대로 적는다(욕설 포함).
- `(※드립)` 자막은 색이나 크기로 구분한다.
- `※ 기록마다 다름` 같은 주석은 작게, 하단 UI에 가리지 않는 위치에.

### 편집 결과물로 요구할 것
- 최종 영상 (9:16, 60초 이내)
- 컷 리스트: | 타임라인 시간 | 클립ID | 원본 구간 | 오디오 처리 | 자막 |
- 원음을 쓴 구간 목록 (저작권 클레임 대응용)
- 욕설 포함 구간 목록 (광고 제한 확인용)

## 5. 저장과 보고

- 결과를 `output/person-shorts/<서울날짜>_<인물>/` 아래에 저장한다.
  - `01_scenes.md` (STEP 1), `02_clips.md` (STEP 2), `03_script.md` (STEP 3), `04_edit_spec.md` (STEP 4)
  - 녹화한 클립은 같은 폴더의 `clips/`에 클립ID 이름으로, 받은 원본 구간은 `src/`에.
- 채팅 답변에는 STEP 1 표 요약(상위 장면), STEP 3 대본 표 전체, 녹화 결과(성공/실패 구간), 확인 필요 항목, 저장 경로를 보여준다.
- 녹화하지 못한 구간이나 확인하지 못한 링크는 그 사실을 그대로 적는다.
